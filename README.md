# AudioVisualText（音美文）
Deconstruction and creative methodology for Audio, Visual, and Text — built on four-dimensional perceptual parameters.
- 音美文创作方法论 —— 基于四维感知结构（音/美/文）的组装教程与创作工具

## 核心架构
- 解构方法：从海量优质音美文作品中识别共同结构
- 系统定义：用听觉、视觉词语定义共同结构名称，实现音美文协同一体化
- 重构方法：打乱共同结构排序铺设小说大纲/旋律伴奏/美术构图骨架，再用感性填充人物言行/歌词撰写/五官形体细节

## 可拆卸结构（音乐架构）
- 音乐：声色（轻重（当前音区高低音阶）／软硬（幼长年龄）／清哑（咬字辨识度）／细粗（转性））、声高（高低音区）、声速（快慢）、音律（拖长短促/连唱断唱）
- ——声色材质：【软奶】hanser-文晓依-山新-泠鸢-银临-兰音-陶典-谢莹-茶理理-三无-祖娅纳惜【硬苏】
- ——#排序仅供参考：喉咙的声带厚度、腔体宽度组成的共鸣空间决定声色材质
- ————基础发声：鼻音（哑重闷感冒）、咽音（哑轻尖夹子）、鼻腔共鸣（萝莉）、咽腔共鸣（御姐）、胸腔共鸣（变粗转性）、口腔共鸣（融合出口）
- ——————混合发声：鼻腔+咽腔（少女）、鼻腔+胸腔（女性正太感）、鼻腔+咽腔+胸腔（女性少年感）、咽腔+胸腔（女性大哥感）、咽腔+极度胸腔（苍老奶奶）
- ——乐器和声：替换音色+音阶和弦+和声密度#可参考litterzy李特基原曲改土味视频
- ————低音伴奏Pad音色材质：贝斯、鼓、钢琴、吉他
- ————中高音主旋律Lead音色材质：电子合成音或弦乐管乐打击乐
- ——————打击乐：钢琴、鼓等
- ——————弦乐：吉他、古筝、提琴、二胡等
- ——————管乐：长笛等
- 注释：我觉得国内配音真的非常棒读，从头到尾都是一个调子，轻重音阶一样，快慢一样，长短一样，发声部位也固定，根本没有感情变化啊大伙

## 可拆卸结构（美术架构）
- 美术：维度（面体／图层／阴影面／轮廓线）、光泽（滑糙）、色泽（深浅／艳灰／暖冷／线下涂色和电子绘色）、动律（透视方向/快慢顿灵）
- ——无论你用什么工具，画笔涂面、建模渲染，本质上都是为了实现构图视觉效果。无法判断透视和打光的结构是否成立，单纯调渲染参数有什么意义，调出来也显得假或别扭。
- 注释：美术我都懒得写，构图建模是人工，填细节基本都是AI跑的，顶多人工再最后微调一下
- ——甚至很多精修都是糊弄的，比如：选区边缘贴图感、光影方向不对、噪点颗粒不匹配、扩图透视崩塌等​这些需要检查的地方
- ——建模的渲染基本都是实习生去跑参数，主美觉得结构呈现满意了再把这套参数固定下来，从个体角色建模扩用到全体角色建模，个别角色复杂度太高的话精修一下交付
- ——你渲染参数好坏的评判标准就是结构呈现是否成立
- ——透视和光影你们自己去看现实水果杯子或者抖音美女视频

## 可拆卸结构（文学架构）
- 文学：嚼字（简冗）、平仄（抑扬）、意境（雅鄙）、文律（齐歪）
- ——诗歌曲词：抑扬平悬情绪骨架+意境（骈文雅词/对比反差/打油诗）+文律（整齐记忆锚点、散歪递进叙事）+嚼字（朗朗上口/嘴巴打架）+平仄（音阶落差情绪波动）
- 小说/游戏文案：你打好抑扬平悬情绪节奏大纲骨架，情节血肉你就自己填啊，人物言行举止靠你的感性和逻辑修正，你不靠感性写文本和AI拟合算法匹配概率缝合尸块有什么区别？
- ——人物冲突：比如说，定义者和蔑视者碰面，定义者“你的失败已是定局，别挡路”，蔑视者“就你也配？再不滚开老子拿你头盖骨当碗使！”
- ——剧情创新：剧情类型早就被人类写完了，你根本没必要在剧情上下功夫，你只需要把人物塑造写好、开篇搞点噱头、断章挖坑留悬念、金手指搞点有意思的

## 音美文一体化（和鸣共奏）
- 整体协调：比如日术曲，画面风格、旋律伴奏、人声文案都是一个整体，画面快速跳动给你视觉锚点，旋律抑扬顿挫给你听觉锚点，文案叙事递进讲一个共情故事
- ——日术曲有的作曲编曲也挺拉的，全靠画面美术撑场，去掉画面和P主知名度完全是路边一条
- 割裂问题：国内二游真的无力吐槽，配音声线完全不贴美术人物，日式文案完全不贴本土配音，音美文全是割裂的

### 2洛天依AI的声色声轨与人工精调
- 这个视频讲音乐，洛天依AI制作歌曲的原理，首先来看洛天依AI的这个虚拟歌姬声库AI模型怎么训练的，主要是采集人的声色材质和唱歌片段喂给AI训练声轨，AI模型训练完成后，就可以一键自动AI生成歌曲底版了，这个又分为自然翻唱和声乐分离两种路径，自然翻唱不经调校就是那种哈基米、曼波音乐，那种声音本来就很鬼畜抽象了，直接输出就行，然后来看，结构化歌曲制作也是自然翻唱，加了声乐分离，自然翻唱就是按照原唱歌曲制作一个声轨同步的底版，声乐分离就是把原唱歌曲的旋律伴奏和人声干声进行分离，两种都行，就是一起调校和分开独立调校的区别，这个调校环节，又分为调校人声和调校旋律，人声的声质就是那个声色材质，根据发音部位切换声色，理论上来说，每个人都是可以切换声色的，主要看训练，你日常说话就是口胡的，正经说话要改变声带的振动模式，真声带和假声带协同控制声质的轻/重、硬/软、清/哑、奶/苏，根据这个一维线参数滑动原理，你就可以把声色变形，然后看声高和滑音，就是音量高低和音速快慢，两者协同就是情感语气，生气高音急促，悲伤低音迟钝，接下来这个人声还需要去除杂音，那种混乱片段干扰歌曲，之后是调校旋律，旋律也是滑音和声高，只不过改叫音高，这两个进行协同就是旋律跳动，让旋律自主表达情绪变化，最后声色变形、情感语气、旋律跳动三合一进行歌曲输出，然后这个歌曲制造又分为官方训练声库和私人训练声库，官方的就是洛天依AI嘛，私人的就是冬雪莲AI那种喂视频，下个视频讲结构感调校，让旋律讲故事，人声也在讲故事，双剑合璧，进行混响输出，形成有重量不悬空的空间感，原创歌曲的话，就是歌词撰写和作曲编曲两个独立模块，把歌词喂给歌姬声库，生成一个原唱底版，作曲编曲就是设计主旋律和伴奏，前奏、主歌、副歌，设计完再用对应的乐器进行演奏录音，拿到软件上调校，然后来看这个歌姬声库进行说话片段声轨训练，把喂唱歌片段换成喂说话片段，然后进行AI语音输出，这个就是我机娘的输入文本进行AI语音自动生成原理，然后来看这个调校啊，其实就是多个一维线参数滑动，这跟我提出的心理学新系统，人格状态机理论完全一致，人格心理、声色声轨、乐器旋律、美术构图都是这套理论。
### 3洛天依歌曲之调校旋律，歌曲矩阵对比

- 这几天都在忙着加固AI封锁，抽点时间给你们讲一下音乐，他这个土嗨洛天依+基础科普宣传我觉得挺有意思的，而且他这个词的音阶错落还挺朗朗上口的，很洗脑，这期就不无谱干讲了，我们对着他的编辑器来讲，这里其实就是调了000停顿的时值长度，手指按键位不松开，可以听见每个音符框都是相同发音时长，空音长度不一样，短的衔接音阶快，长的衔接音阶慢，就变成了快敲慢敲，这里差不多，依旧是C7音区上下，衔接比刚才快了一点，都是一个音阶一个音阶敲，没有和弦（多个音阶同时敲），这里是两个音区的和声，一个偏高音区，一个偏低音区，按一下低，再按一个高，反复循环，然后往下跳一个音阶，第三个时间段跳两个白键位，其实就是往下跳了两个音阶，这里是打击乐的和弦，两键位+单键位+两键位反复敲，这反拍贝斯就是时值长度落在后半拍的意思，整体是一拍，用于插在两次鼓声停顿的空隙里，贝斯+鼓很常用的，写法是，0是一拍起点，0.5是中间位置，1是下一拍起点，这里不是完全改0停顿长短了，而是1234567拖音长短，实心就是1234567音阶，空心就是0停顿的空音，这里就是把前面的全部旋律伴奏合起来，变成和声，加上洛天依按主旋律唱歌词，就是开头那个完整歌曲了。
