# AudioVisualText（音美文）
Deconstruction and creative methodology for Audio, Visual, and Text — built on four-dimensional perceptual parameters.
- 音美文创作方法论 —— 基于四维感知结构（音/美/文）的组装教程与创作工具

## 核心架构
- 解构方法：从海量优质音美文作品中识别共同结构
- 系统定义：用听觉、视觉词语定义共同结构名称，实现音美文协同一体化
- 重构方法：打乱共同结构排序铺设小说大纲/旋律伴奏/美术构图骨架，再用感性填充人物言行/歌词撰写/五官形体细节

## 可拆卸结构（音乐架构）
- 音乐：声色（轻重（当前音区高低音阶）／软硬（幼长年龄）／清哑（咬字辨识度）／细粗（转性））、声高（高低音区）、声速（快慢）、音律（拖长短促/连唱断唱）
- ——声色材质：【软奶】hanser-文晓依-山新-泠鸢-银临-兰音-陶典-谢莹-茶理理-三无-祖娅纳惜【硬苏】
- ——#排序仅供参考：喉咙的声带厚度、腔体宽度组成的共鸣空间决定声色材质
- ————基础发声：鼻音（哑重闷感冒）、咽音（哑轻尖夹子）、鼻腔共鸣（萝莉）、咽腔共鸣（御姐）、胸腔共鸣（变粗转性）、口腔共鸣（融合出口）
- ——————混合发声：鼻腔+咽腔（少女）、鼻腔+胸腔（女性正太感）、鼻腔+咽腔+胸腔（女性少年感）、咽腔+胸腔（女性大哥感）、咽腔+极度胸腔（苍老奶奶）
- ——乐器和声：替换音色+音阶和弦+和声密度#可参考litterzy李特基原曲改土味视频
- ————低音伴奏Pad音色材质：贝斯、鼓、钢琴、吉他
- ————中高音主旋律Lead音色材质：电子合成音或弦乐管乐打击乐
- ——————打击乐：钢琴、鼓等
- ——————弦乐：吉他、古筝、提琴、二胡等
- ——————管乐：长笛等

## 可拆卸结构（美术架构）
- 美术：维度（面体／图层／阴影面／轮廓线）、光泽（滑糙）、色泽（深浅／艳灰／暖冷）、动律（顿灵）
- ——无论你用什么工具，画笔涂面、建模渲染，本质上都是为了实现光影视觉效果。作为创作者，无法判断透视和打光的结构是否成立，单纯调渲染参数有什么意义，调出来也显得假或别扭。​

## 可拆卸结构（文学架构）
- 文学：嚼字（简冗）、平仄（抑扬）、意境（雅鄙）、文律（齐歪）
- ——诗歌曲词：抑扬平悬情绪骨架+意境（骈文雅词/对比反差/打油诗）+文律（整齐记忆锚点、散歪递进叙事）+嚼字（朗朗上口/嘴巴打架）+平仄（音阶落差情绪波动）
- 小说：你打好抑扬平悬情绪节奏大纲骨架，情节血肉你就自己填啊，人物言行举止靠你的感性和逻辑修正，你不靠感性写文本和AI拟合算法匹配概率缝合尸块有什么区别？
